# 国家基本比例尺点综合约束

本项目已将点综合规则改为优先受国家基本比例尺序列约束，而不是只靠经验删点。

## 采用的国标框架

- 国家基本比例尺地图图式
  - `GB/T 20257.1-2017`：`1:500 1:1000 1:2000`
  - `GB/T 20257.2-2017`：`1:5000 1:10000`
  - `GB/T 20257.3-2017`：`1:25000 1:50000 1:100000`
  - `GB/T 20257.4-2017`：`1:250000 1:500000 1:1000000`
- 国家基本比例尺地图编绘规范
  - `GB/T 12343.2-2009`：`1:5000 1:10000`
  - `GB/T 12343.1-2008`：`1:25000 1:50000 1:100000`
- 国家基本比例尺地图产品标准
  - `GB/T 33176-2016`：`1:500 1:1000 1:2000`
  - `GB/T 33177-2016`：`1:5000 1:10000`
  - `GB/T 33180-2016`：`1:25000 1:50000 1:100000`
  - `GB/T 33181-2016`：`1:250000 1:500000 1:1000000`

## 当前系统策略

- 任意目标比例尺先吸附到最近国家基本比例尺档。
- 仅在同一国标序列内插值，不跨大档位做激进外推。
- 对点要素不再允许在中小比例尺阶段用极低保留率直接压缩到接近清空。
- 先满足类别存在性、空间覆盖、骨架连续性，再做屏幕冲突消解。

## 说明

- 国家标准通常按基础地形图产品、图式、编绘规范规定不同尺度下应表达的要素类型、图面表示和编绘要求。
- 对专题 POI（如银行、医院、学校、停车场）并不存在一个公开统一的“逐类别固定保留百分比”国标表。
- 因此本项目采用“国家基本比例尺档位约束 + 点图面可读性约束 + 结构/语义保真”的保守实现。
