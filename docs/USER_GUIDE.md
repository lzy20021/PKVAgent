## 1. 快速入门

### 1.1 安装与配置
- 安装依赖：`pip install -r requirements.txt`
- 启动程序：`python main.py`
- 配置入口：状态栏 `Configure` 或菜单 `配置 -> 环境配置`

### 1.2 第一个任务：道路简化
输入示例：

```text
对 roads.shp 进行 Douglas-Peucker 简化，容差 10 米
```

### 1.3 界面介绍
- 左侧：图层与工作区管理
- 中间：地图画布
- 右侧：AI 助手面板
- 底部：环境状态栏（Python/QGIS）

## 2. 核心功能

### 2.1 智能算法生成

系统根据自然语言输入自动完成：
- 任务识别（如简化、缓冲区、叠加）
- 参数提取（如容差、距离、字段）
- 代码生成与执行

好的描述示例：
- `对 roads.shp 进行 Douglas-Peucker 简化，容差 10 米`
- `将 buildings.shp 按 district 字段合并`
- `对 points.shp 创建 100 米缓冲区`

不好的描述示例：
- `简化道路`
- `合并建筑物`
- `做缓冲区`

### 2.2 环境配置

- Python 环境：必需，建议具备 `geopandas`、`shapely`、`fiona`、`pyproj`
- QGIS 环境：可选，某些 QGIS 生态能力依赖此环境
- 状态栏颜色说明：
  - `✅` 可用
  - `❌` 不可用
  - `⚠` 未检测

### 2.3 图层管理

支持：
- 图层加载、显示/隐藏、样式调整
- 图层顺序调整
- 导出处理结果

### 2.4 结果查看

建议每次执行后检查：
- 输出图层是否生成
- 几何质量是否满足预期
- 要素数量、属性字段是否正确

## 4. 最佳实践

### 4.1 如何描述任务
使用模板：
`对 <文件> 执行 <算法/操作>，参数 <值+单位>，约束 <如保拓扑>`

### 4.2 参数设置技巧
- 简化容差：小尺度图可取更大值
- 缓冲距离：明确单位（米/千米）
- 聚类参数：说明邻域距离和最小样本数

### 4.3 性能优化建议
- 大数据先裁剪再分析
- 距离计算前转换到投影坐标系
- 复杂流程拆成多个小步骤执行

### 4.4 错误处理
- 路径错误：检查文件名、绝对路径
- 坐标系警告：先转换 CRS 再算距离
- 库缺失：补装依赖后重试
- 内存不足：分块处理、抽样、简化几何

## 5. 常见问题（FAQ）

### 5.1 环境配置问题
1. **Python 显示不可用怎么办？**  
检查路径是否指向真实 `python.exe`，并确认安装了依赖库。

2. **QGIS 一直不可用怎么办？**  
确认选择的是 QGIS 安装根目录，且目录下含相关运行组件。

3. **为什么状态栏是 ⚠ 未检测？**  
说明尚未执行验证，打开“环境配置”点击 `Verify Now`。

### 5.2 算法执行问题
4. **任务执行失败但没有输出？**  
先检查输入文件是否存在，再查看日志中的报错堆栈。

5. **结果不符合预期？**  
通常是参数太激进或任务描述不完整，补充约束后重试。

6. **生成了错误算法怎么办？**  
在输入中明确算法名与关键参数，例如“使用 Douglas-Peucker”。

### 5.3 数据格式问题
7. **支持哪些格式？**  
常见矢量格式如 SHP、GeoJSON、GPKG 均可。

8. **中文字段乱码怎么办？**  
优先使用 UTF-8 编码数据，必要时转换后再导入。

### 5.4 性能问题
9. **执行速度很慢怎么办？**  
先裁剪研究区，或只处理必要字段与必要图层。

10. **大文件容易内存不足怎么办？**  
采用分块处理；先简化后分析；避免一次加载过多图层。

## 6. 附录

### 6.1 支持的数据格式
- SHP
- GeoJSON
- GPKG

### 6.2 支持的坐标系
- EPSG:4326（WGS84）
- EPSG:3857（Web Mercator）
- 常见 UTM 分区（如 EPSG:32649）

### 6.3 术语表
- **容差（Tolerance）**：几何简化允许的偏移阈值
- **拓扑保持**：保持相邻关系与几何一致性
- **空间连接（Spatial Join）**：按空间关系进行属性关联
- **投影坐标系**：用于更准确距离/面积计算的坐标系
